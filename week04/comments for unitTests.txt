Since you're studying software development, you don't need to know everything about unit testing right away. Focus on the key concepts that lecturers, assignments, and interviews commonly expect.

What is Unit Testing?

A unit test checks that one small piece ("unit") of code works correctly.

For example, if your program has:

public decimal Add(decimal a, decimal b)
{
    return a + b;
}


A unit test checks:

Add(2, 3)


returns:

5


The goal is to find bugs early and make sure code continues working after changes.

The Arrange-Act-Assert Pattern (AAA)

Most unit tests follow this structure:

[Test]
public void Add_TwoNumbers_ReturnsSum()
{
    // Arrange
    var calc = new Calculator();

    // Act
    var result = calc.Add(2, 3);

    // Assert
    Assert.That(result, Is.EqualTo(5));
}

Arrange

Set up the objects and data needed.

var calc = new Calculator();

Act

Run the method being tested.

var result = calc.Add(2, 3);

Assert

Check the result.

Assert.That(result, Is.EqualTo(5));

Important NUnit Attributes
[TestFixture]

}

}


Used to clean up resources.

What Makes a Good Unit Test?

✅ Tests one thing only

Add(2,3)


instead of testing many methods together.

✅ Has a clear name

OutstandingBalance_NoPayments_ReturnsFullFee


✅ Easy to read

Other people should quickly understand it.

✅ Gives the same result every time

Avoid depending on:

Current date/time
Internet
Databases
User input

unless necessary.

What Is the Purpose of Unit Testing?
1. Find Bugs

If a method stops working, tests fail.

2. Prevent Regression

Regression means:

You fix one thing and accidentally break another.

Tests catch these mistakes.

3. Improve Confidence

When all tests pass:

Passed: 25
Failed: 0


you can be more confident the code works.

Common Exam or Assignment Questions

You should be able to explain:

What is unit testing?

Unit testing is the process of testing individual units of code, such as methods or functions, to ensure they work correctly.

What is NUnit?

NUnit is a testing framework for .NET applications that allows developers to create and run automated unit tests.

What is Arrange-Act-Assert?

A testing pattern where test data is prepared (Arrange), the method is executed (Act), and the result is verified (Assert).

Why is unit testing important?

It helps detect bugs early, prevents regressions, improves software quality, and makes code easier to maintain.
